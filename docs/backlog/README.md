# Backlog

Esta carpeta contiene la definición funcional del backlog de **PlayerTech**, organizada en épicas e historias de usuario.

## Estructura

```text
backlog/
├── epics/              # Épicas y sus objetivos funcionales
├── user-stories/       # Historias de usuario y criterios de aceptación
└── README.md
```

## Organización

- **Épicas:** agrupan funcionalidades relacionadas bajo un objetivo común.
- **Historias de usuario:** describen necesidades concretas del usuario y sus criterios de aceptación.

Las épicas y las historias de usuario representan la **definición funcional del producto**. Los detalles técnicos de implementación se mantienen en `specs/`.

## MVP v1

El backlog actual corresponde al **MVP v1 de PlayerTech** y podrá evolucionar conforme se validen nuevas necesidades del producto.
