# EP-03 — Gestión de grupos y categorías

## Objetivo

Permitir organizar a los jugadores de acuerdo con la estructura deportiva de la academia.

## Alcance

- Crear grupos o categorías.
- Consultar grupos o categorías.
- Asociar jugadores.
- Consultar integrantes.
