# EP-05 — Gestión de convocatorias

## Objetivo

Permitir al administrador convocar jugadores para participar en una actividad.

## Alcance

- Crear convocatoria a partir de una actividad.
- Seleccionar jugadores convocados.
- Publicar convocatoria.
- Generar enlace temporal.
- Asociar la convocatoria con los jugadores correspondientes.
