# Maquetas (R9, FR-019)

Maquetas de baja fidelidad a 360 px, aprobadas por el responsable el 2026-10-21 (con el nombre liviano de la opción 1 y «Sí» directo en la pantalla 5). Versión publicada: https://claude.ai/artifact/Bv5KRTmiBxuZzQmoQa2kES (privada).

| Archivo | Pantalla |
|---|---|
| `Main.dc.html` | Enlace: elegir por quién respondes (nombre, inicial y apodo; buscador; ayuda si no aparece) |
| `Identify.dc.html` | Enlace: identificarte (nombre, celular, parentesco, autorización de datos) |
| `Respond.dc.html` | Enlace: responder Sí, Sí provisional o No, con motivo opcional y «Cuéntanos» para *Otro* |
| `Done.dc.html` | Enlace: «¡Listo!», cambios restantes, «Cambiar respuesta» y «¿Respondes por alguien más?» |
| `Remembered.dc.html` | Enlace: dispositivo recordado con hermanos y un jugador que ya no está convocado |
| `Closed.dc.html` | Enlace: convocatoria cerrada (o actividad cancelada) en modo lectura |
| `NotFound.dc.html` | Enlace: «Esta convocatoria ya no está disponible», sin datos |
| `Tracking.dc.html` | Owner: sección «Convocatoria» con totales, «Actualizar», «12/17» y estado por jugador |
| `PlayerDrawer.dc.html` | Owner: drawer del jugador con respuesta actual, validar o rechazar, historial y «Registrar respuesta» |
| `PlayerPending.dc.html` | Owner: ficha del jugador con el bloque «Por validar» |

El aspecto final lo da `DESIGN.md`.
