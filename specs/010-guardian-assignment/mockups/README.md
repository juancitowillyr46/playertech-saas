# Maquetas aprobadas (R6, FR-010)

Maquetas de baja fidelidad a 360 px, aprobadas por el responsable el 2026-10-18. Versión publicada: https://claude.ai/artifact/2Wivkw9BpxjTPsVZ4G7Twf (privada). Los archivos `.dc.html` son la copia de esa versión.

| Archivo | Pantalla |
|---|---|
| `Main.dc.html` | Ficha del jugador: «Agregar acudiente» y «Copiar de un hermano» |
| `Picker.dc.html` | Lista de acudientes con buscador, a quién acompaña cada uno, el ya asignado deshabilitado y «Registrar un acudiente nuevo» |
| `PickerSelected.dc.html` | Acudiente elegido con el parentesco; sin autorización |
| `CopySibling.dc.html` | Copiar de un hermano: elegir al hermano y sus acudientes marcados, con el parentesco editable |

Las maquetas 2 a 4 muestran el contenido de un drawer (`FormDrawer`, como en la spec 009). El aspecto final lo da `DESIGN.md`. Detalle: `../contracts/ui-contracts.md`.
