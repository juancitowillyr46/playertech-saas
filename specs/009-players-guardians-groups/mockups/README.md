# Maquetas aprobadas (R9, FR-016)

Maquetas de baja fidelidad a 360 px, aprobadas por el responsable el 2026-10-18. Versión publicada: https://claude.ai/artifact/LFBqM4NQeoAQhcm7rCGMsN (privada). Los archivos `.dc.html` son la copia de esa versión.

| Archivo | Pantalla |
|---|---|
| `Main.dc.html` | Listado de jugadores |
| `PlayerForm.dc.html` | Registrar jugador con el aviso de jugador ya registrado |
| `PlayerProfile.dc.html` | Ficha del jugador con sus acudientes |
| `AddGuardian.dc.html` | Agregar acudiente con un celular ya registrado |
| `Groups.dc.html` | Listado de grupos y crear grupo |
| `Group.dc.html` | Grupo con integrantes y agregar jugadores |
| `NavB.dc.html` | Navegación elegida: Grupos como pestaña dentro de Jugadores |

Condiciones de la aprobación:

- **Navegación B**: Jugadores en la barra, con las pestañas Jugadores y Grupos. Deja espacio para Actividades en la spec 2.
- **Formularios en drawer**, como en Sedes: registrar o editar jugador, acudiente y grupo, y agregar jugadores. Las maquetas 2, 4, 5 y 6 muestran el contenido, no el contenedor.
- El aspecto final lo da el sistema visual Planilla (`DESIGN.md`). Las maquetas fijan estructura, contenido y textos.
